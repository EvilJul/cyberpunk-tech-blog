## Context
文章已有 cover_media_id 和媒体表；封面尚未在编辑和列表形成完整交互。保存只写工作副本，发布提升公开快照。

## Goals / Non-Goals
目标：可控置顶、可选封面、紧凑轮播、手机适配和权限回归。非目标：改变发布流程、自动发布、外部推荐算法或线上部署。

## Decisions
- 置顶是独立推荐元数据：articles.pinned 默认0，管理员 PUT /api/studio/articles/:id/pin，body 为 {pinned: boolean}，沿用 If-Match 和共享 revision；仅已发布文章可置顶。更新不得提升草稿、不得改变正文。DTO 返回 pinned 布尔值。
- GET /api/articles/featured/list 返回 {data: [...]}，只读已发布且置顶的公开快照，限制数量；列表与推荐含 cover_image。公共查询不暴露草稿。
- 复用 cover_media_id，封面可从已有媒体选择或上传。保存封面仅写副本，发布生效；清除封面支持 null。
- 搜索下、分类上仅在首页无筛选时显示轮播。首次洗牌，6秒轮换，悬停、焦点、后台、减少动态效果时暂停；支持永久暂停和前后切换。0篇隐藏，1篇静态。
- 推荐使用全幅封面与底部渐变叠字，桌面约360px、手机约330px；普通列表右侧缩略图，无图保持文字布局。图片失败降级，不留下损坏图标；部署前缀沿用现有 URL 工具。

## Risks / Trade-offs
- 推荐与普通列表可能重复 → 保留完整列表和分页语义，不在客户端删条目。
- 置顶即时影响公开展示 → 按钮明确“首页置顶”，与发布动作分离，权限及过期版本检查。
- 背景影响阅读 → 保留主题色，轻度模糊与摘要行数限制。

## Migration Plan
SQLite 幂等增量字段与索引，在一次性库验证升级和重启。回退应用时保留新增列；部署前依现有迁移指南备份，不执行真实上线。

## 推荐区视觉迭代
根据实际预览反馈取消外置标题与计数工具栏，控制按钮叠放于封面内，指示条收进卡片；使用已有 Motion 依赖实现450ms淡出滑移与进入，文案轻微错峰进入。减少动态效果时直接切换。

## 首页杂志式视觉迭代
首页增加简短引言，搜索下方保留精选推荐，封面铺满推荐区，标题和摘要通过深色渐变保持对比度。普通列表在桌面采用轻表面和分隔线；侧栏合并作者与统计，隐藏未配置联系入口。手机复用原有作者条、隐藏桌面引言，保留底部导航和可读卡片。搜索输入期间引言保持稳定，避免搜索框上下跳动。

## 首页引言位置迭代
桌面引言迁至左上角独立栏，标题分为两列竖排，长说明仅保留无障碍文本；不再占用主栏顶部。左栏与导航共用弹性布局，矮窗口缩小字号和导航行高，空间不足时允许左栏独立滚动。手机继续复用作者条。

## 编辑器属性视觉迭代
Markdown 工具栏统一使用图标与中文悬停／键盘提示；正文上传入口保留粘贴和拖放能力。封面采用固定比例预览、紧凑上传和清除按钮，媒体库默认折叠，缩略图按钮使用独立网格，长文件名单行省略。文章地址与作者移入高级设置，保留自动生成地址、现有署名和修改已发布地址时的确认。
