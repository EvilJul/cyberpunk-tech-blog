## Goals / Non-Goals

**Goals:**

- 手机首屏能辨认站点和文章，主要任务为发现文章、阅读、查找、联系作者。
- 访客、普通登录用户、管理员共享稳定导航布局，入口变化不挤压读者操作。
- 背景体现个性，文本和操作有稳定表面；保留文章已完成的阅读底板。
- 所有关键页面覆盖加载、空、失败、长文本、大数据、软键盘、旋转、安全区与无障碍。
- 用户从文章返回后能继续先前的搜索/筛选/页码与位置，不反复重新找内容。
- 使用现有数据、组件和接口，计划能拆成有先后依赖和验收证据的实施任务。

**Non-Goals:**

- 不重设计工作台、不新增发布/认证能力、不改后台设置存储。
- 不增加推荐流、轮播、热门榜、站内私信、个人中心、无限滚动或虚构指标。
- 不新增主题切换、固定顶部通栏导航、PWA/离线模式、第三方字体或 UI 依赖。
- 不在本计划阶段修改运行代码、真实配置、文章或部署。

## Decisions

### D1. 手机采用“内容先行”，独立组织信息而非重做整个应用

≤760 CSS px 使用移动读者布局；761–1023px 验证过渡布局，≥1024px 保留桌面主要结构。保留现有路由、SettingsProvider、ThemeProvider、鉴权和数据契约。横屏可按实际 CSS 宽度进入过渡布局，但高度和键盘不能被宽度规则忽略。

移动端首页直接使用作者背景横幅，ContactLinks 收进更多/关于，不渲染完整 Sidebar 再用 CSS 隐藏；否则仍会触发无意义的侧栏请求。首页内容和移动身份展示共用 settings。探索目录和列表计数复用现有响应，不逐卡请求统计。

**备选与取舍：**只加 media query 成本低，但保留了所有重复信息；另建独立移动 SPA 会复制路由和业务。因此采用同一应用、共享业务、局部呈现组件的方式。

### D2. 首页布局与首屏预算

首页从上至下：

1. **作者背景横幅**：40px 头像或名字首字、18px 名字、两行简介和 44px 命中范围的关于入口；原背景局部裁切，加深色遮罩并向下渐隐，不固定，不是顶部导航通栏。
2. **联系方式**：按用户最新确认，手机首页移除三个独立账号图标；GitHub、邮箱、公众号统一放更多/关于，继续沿用空配置灰显/有效配置点亮。完整简介从关于入口阅读。
3. **搜索框**：48px 高，中文提示“搜索文章”，手机不显示仅桌面适用的 `/` 快捷键提示。
4. **文章区标题**：“最新文章”，右侧“浏览分类”进入探索。首页不再完整重复一套分类/标签筛选和统计面板。
5. **文章列表**：单列，真实内容卡片；正文开头即有意义，不依赖封面图。
6. **简化分页**：上一页 / 当前页与总页数 / 下一页，紧凑且可换行；不显示五个数字页码横排。
7. **轻量页脚**：版权和有效订阅入口，留足底栏空间；作者、统计、目录不在此再次成套堆叠。

在 390×844 与 360×800、100% 缩放、已加载且有文章时，首篇文章标题顶部应位于视口上方 280px 内；首篇卡片的标题及主要元信息位于底栏上方可见区域。长站名允许截断，完整名称可访问；不通过缩小字体、删真实正文或伪造卡片满足预算。200% 缩放以可操作和不遮挡为准，不强制该像素预算。

│ [头像] 站点名称              │
│        两行简介    关于我 ↗  │
│   背景局部裁切，渐变融入底色 │
│ [🔍 搜索文章              ] │
│ 最新文章          浏览分类 › │
│ ┌─────────────────────────┐ │
│ │ 分类 · 日期              │ │
│ │ 足够辨认的两行文章标题   │ │
│ │ 摘要最多两行……           │ │
│ │ 约 4 分钟    阅读 · 喜欢  │ │
│ └─────────────────────────┘ │
│ 下一篇文章……                │

`sidebar=hidden` 不隐藏站点身份横幅与更多中的联系入口，只隐藏完整侧栏；如果实现发现该设置当前含义与此冲突，先核对 owning source，记录兼容映射，不重置用户配置。桌面左右/隐藏侧栏语义保持。

### D3. 四项固定底栏和更多面板

固定四等分：**首页、探索、搜索、更多**，按当前可用宽度分配，每项命中区域 ≥44×44px，文字 11–12px，图标 20–22px。栏主体高度约 64px，底部增加 safe-area；不使用桌面导航的 4:2 拆分。

- 首页/探索为路由链接；搜索/更多为真实按钮，不能假装新页面链接。
- 搜索：列表页聚焦现有搜索框并保留条件；文章/关于/404 无搜索框时打开已有站内搜索弹层，地址与阅读位置不变。
- 当前项：首页只在首页选中；探索含旧分类/标签直达页；文章页不谎称在首页，保留四项，搜索/更多仅在各自打开时标记展开。
- 更多面板：作者简介、联系账号、关于作者、RSS；未登录显示登录，管理员显示进入工作台，其他角色不显示无权限写入入口。不创建“我的”页面，不在底栏再加入写文章或工作台。
- 创建文章仍从工作台侧栏“新建文章”进入，保留已确认单入口意图；桌面读者导航是否保留已有快捷入口不在本期删除。
- 更多/搜索/公众号共用清晰的弹层协调：一次只激活一个模态。由更多打开公众号时保留返回目标，关闭后恢复更多及正确焦点；由首页图标打开则回到该图标。不得叠两个滚动锁或恢复到已卸载节点。

**备选与取舍：**三项底栏再隐藏搜索会损失跨页查找；六项底栏对角色和窄屏过敏；固定四项在稳定性与发现性之间更合适。没有固定顶部导航，也没有新增主题切换。

### D4. 文章卡片、摘要与分页

| 内容 | 手机规则 |
| --- | --- |
| 卡片 | padding 16px，间隔 12–16px，圆角 12–16px；不透明内容表面 |
| 标题 | 19–20px、600、行高 1.4–1.5，最多两行；可访问名称保留全文 |
| 摘要 | 14–15px、行高 1.65，最多两行；无摘要不留空占位 |
| 元信息 | 12–13px，日期/分类可换行；标题仍为主要视觉信息 |
| 标签 | 至多两项，过长省略但可访问全文；更多标签在探索/正文可达，不使用标签云填满卡片 |
| 时长/统计/点赞 | 分成稳定区域，大数字不挤压标签；点赞按钮 ≥44px 命中范围 |
| 无封面 | 不加占位插图、不重复头像，不新增封面抓取请求 |
| 文章入口 | 保留整卡主要命中区；分类、标签、点赞各自操作不能触发进入文章 |
| 分页 | 当前页明确、边界禁用、翻页后在结果区定位；结果变少时合法纠正页码，无循环请求 |

截图中的摘要出现 Markdown 图片源码是独立内容呈现问题，纳入本计划：检查文章列表摘要接口与现有摘要生成约定，只在摘要/摘要片段展示中转换为纯文本，移除图片和链接的语法噪声；不改写保存的摘要、正文及原始 Markdown，不引入另一个 Markdown 库。若已有服务端纯文本摘录可复用，优先复用；不得从每卡详情补请求生成摘要。

### D5. 探索页采用“已选条件 + 可收起的筛选”

保持 `/explore` 和分类/标签旧链接，category/tag 仍分别筛选，不合并后台实体。标题 24px、说明一行、搜索框、已选条件、结果构成主线。

- 分类初始最多两行；标签默认显示前 8 项及“全部标签（数量）”，无数据时不造数量或假项。
- 已选项必须在摘要条显示，单项可清除；不论其排序是否前 8 都不能消失。已选项不计入额外隐藏候选数量。
- 展开长目录使用可滚动面板/抽屉，支持本地筛选选项，不新增服务端接口；确认后收起，焦点回“筛选”，结果区宣告更新。
- 30 分类/100 标签、长连续英文名称时，默认筛选块不超过 240px；完整选择能力不被数量截断。
- 筛选/搜索变化回第 1 页；保留另一条件和关键词。按钮“清除全部”清空筛选及搜索，回第一页，语义明确。
- 结果更新不每次把用户甩回页面顶部；显式翻页滚到结果标题，筛选抽屉确认后确保结果入口可见并尊重减少动效。

```text
探索文章                  [筛选]
[🔍 搜索当前范围               ]
已选：[Python ×] [性能 ×]  清除全部
分类：全部  Python  ……  展开
标签：#性能 #网络 …… 全部标签
──────────────────────────────
找到 12 篇文章
[文章卡片] [文章卡片] ……
[上一页]       1 / 2       [下一页]
```

### D6. 搜索状态与请求先行稳定，再制作动画

复用 SearchBar/ArticleList，不新造第二套搜索协议。列表搜索为 500ms 防抖，中文组合输入完成后再提交，清空立即生效；输入框始终挂载，结果区独立切换状态。

| 状态 | 展示和行为 |
| --- | --- |
| 首次加载 | 搜索/筛选可见，结果骨架或明确加载状态；不展示虚假统计 |
| 更新中 | 保留上一结果但标记正在更新；旧项不可被误称为新条件结果，可在结果区注明“更新中” |
| 真正无文章 | 暂无文章，保持可导航 |
| 真正无匹配 | 无匹配结果，提供清空/调整条件 |
| 网络/服务失败 | 明确失败与重试；保留关键词、筛选、输入与可用旧结果 |
| 快速改词/改筛选 | AbortController + 请求代次保护；只有最新请求可写入列表、页码、总数与错误状态 |
| 离开页面 | 取消请求；取消不记录为用户错误，不用吞掉真实异常来清空日志 |

弹层搜索在手机上采用接近整屏的阅读面板，包含固定可达的标题/关闭按钮、搜索输入、独立滚动结果、简化分页。未输入时允许展示最近发布列表，但标注“最新文章”，不称为推荐；不新建搜索历史存储。打开是明确用户动作才 autofocus，刷新或结果返回不反复抢焦点。清除按钮可访问，不能只有无名称的 X。

### D7. 地址、返回与滚动状态

公共 URL 约定：`/?q=关键词&page=2`、`/explore?category=名称&tag=名称&q=关键词&page=2`，旧 `/category/:name`、`/tag/:name` 同样支持 q/page。现有 focus=search 是临时聚焦指令，不计入搜索语义和滚动键，可用 replace 消费，重复点击搜索不堆积历史记录。

- page 只接受完整十进制正整数；缺失、0、负数、小数、非数字均按 1，超过 1000000 时先限制到该上限。已知参数重复时取第一次出现的值并去重，用 replace 规范化，page=1 可省略；不生成循环跳转。q/category/tag 同样按首次值读取，不误删无关合法参数。
- 成功响应确认页码超过总页数时，回最后一个有效页并 replace 地址，最多补一次纠正请求；零结果使用第 1 页且禁用前后页。网络失败不视为总数为 0，不擅自重置页码；过期响应不能触发纠正。
- 输入防抖完成用 replace 更新 q，防止每个字符生成一条历史；显式分页、筛选切换使用可理解的历史条目。
- 列表到文章携带已校验的站内 returnTo，保留 q/category/tag/page；不接受跨域、协议相对或编码逃逸的返回地址。
- 列表滚动位置按规范化路由和查询参数保存，优先内存，必要时使用有容量上限的 sessionStorage（最多 20 条）；不持久化认证或评论邮箱、正文。
- 返回列表先恢复条件、加载正确结果，再恢复滚动；因内容减少不能精确定位时靠近结果区。浏览器前进后退与页内“返回列表”一致。
- 文章 A → 站内搜索弹层 → 第二页结果 → 文章 B：选择结果前将弹层 q/page/内部滚动、来源 A 的地址/阅读位置及来源历史条目标识写入当前站内导航状态，再进入 B；不把这些状态写入认证存储或共享 B 的 canonical。B 的页内入口显示“返回搜索结果”。来源条目仍匹配时，页内返回与浏览器返回均回 A 并恢复搜索弹层第二页及内部滚动，关闭弹层后继续阅读 A 的原位置。
- 若来源条目丢失/跨会话/直接分享 B，且有合法的公开 q/page 返回上下文，则返回独立 `/explore?q=...&page=...`；没有合法上下文时回首页。返回上下文必须校验，不能盲目 history.back 离开站点；关闭恢复后的搜索使用 replace 更新弹层状态而不新增历史。
- 直接打开文章无上下文时，返回首页是合理兜底；文章自身直接打开从顶部开始。
- 替换 Layout 中无差别路径变化 scrollTo(0,0)；不是删除所有导航滚动行为。
- 不使用依赖 Data Router 的 API 硬套当前 BrowserRouter；优先局部滚动恢复组件。桌面必须一起回归，公共地址与 API 无破坏性变更。

### D8. 文章页延续独立阅读表面，补齐触控路径

- 保留 `article-reading.css` 已有不透明底色、17px 正文及约 1.85 行高、局部代码/引用/表格配色；绝不让背景再次透进正文。
- 文章标题 26–30px，可完整换行；元信息 12–13px；正文左右 18–20px。手机表单输入使用至少 16px 字体，降低 Safari 输入自动缩放风险。
- 无标题目录时不渲染空“文章目录”盒子；有目录时默认折叠显示“目录（N 节）”，打开后可滚动，点击唯一锚点定位且不被底栏遮挡。
- 代码、宽表格只在各自区域横向滚动，整页不横向滚动；复制有反馈，失败允许手动选中，禁止把长代码强制断行导致难辨结构。
- 图片不超正文宽度，保持原比例；点击预览可关闭、Esc 退出并恢复触发焦点；已有非首屏 lazy/async 保留。
- 阅读页底栏仍四项，回顶部按钮不能藏在底栏后；评论与关键末尾内容加入一致的底部安全留白。

### D9. 联系、关于与模态一致化

更多/关于从 settings 读取真实作者、简介与 ContactLinks；无需依赖 Sidebar 可见性，隐藏侧栏时仍能联系作者。保留空配置灰显、有效地址点亮和危险 URL 拒绝。

公众号信息区包含名称、微信号、可选二维码、复制与关闭；二维码加载失败且存在名称/微信号时，仍可按文字查找；仅配置二维码而图片失败时明确提示“暂时没有可用的公众号资料”，提供重试图片与关闭，不能承诺不存在的搜索/复制路径。只有名称、只有账号、只有二维码均有明确降级文案；二维码最大宽度 min(240px, 内容宽度)，不得挤出按钮。长账号、复制失败、空内容和图片失败均测试；不添加外部账号跳转猜测或模拟扫码成功。

关于页排版为作者身份、简介、联系及有效现有链接；不展示不可用技能统计、文章推荐或追踪数据。RSS 在有真实路径的入口展示。

### D10. 安全区、软键盘与模态滚动

- 统一移动尺寸令牌：`--mobile-gutter` 默认 16px、`--mobile-tabbar-height` 64px、`--mobile-safe-bottom` 来自 env。正文最终留白只由一个布局层负责：底栏高度 + 安全区 + 16px；取消当前 main 与 body 双重固定留白叠加。
- 评估并设置 `viewport-fit=cover`，同时处理 top/left/right/bottom inset；不得只加 meta 而不给横屏安全区留白。保留用户缩放，不设置 maximum-scale=1 或 user-scalable=no。
- 使用 dvh 并提供 vh 降级；可见视口必要时由 visualViewport 维护，不假设 dvh 本身解决全部软键盘问题。
- 输入聚焦且可见高度因软键盘缩小时收起底栏，并同步去掉其占位；关闭键盘后恢复。旋转、地址栏伸缩、捏合缩放不能误当键盘。检测方案在 iOS/Android 真机核对，不靠 UA 字符串硬编码。
- 模态内部只保留一个主滚动容器；标题、关闭按钮和输入始终可达；页面锁滚动在关闭、路由变化、卸载和异常时都恢复。不得因开启弹层把正文滚回顶部。

### D11. 视觉令牌、背景和动效

| 项目 | 约束 |
| --- | --- |
| 内容边距 | 默认 16px，极窄 320px 不低于 12px |
| 基础字号 | 正文 15–16px，文章正文 17px，表单输入 ≥16px |
| 层级 | 页面标题 24px，卡片标题 19–20px，元信息 ≥12px；固定底栏标签 ≥11px |
| 点击范围 | 所有主要交互目标 ≥44×44px；可通过透明 padding 扩大，不挤压文本 |
| 间距 | 8/12/16/24px，独立区块 24px，不多层套大卡片 |
| 阴影与玻璃 | 移动内容不用大 blur/多层光晕；边框和实色区分层级 |
| 颜色 | 常规文字对比度 ≥4.5:1，必要控件边界与焦点 ≥3:1；状态不只靠颜色 |
| 动画 | 120–180ms 反馈；减少动效偏好下不使用平滑滚动和装饰动画 |

手机所有读者页面默认不挂载 PixelSnow/SideRays/SplashCursor/GridOverlay 等装饰特效，保留静态背景图片及已保存参数；这是呈现策略，不把后台 effects 配置改成 false。桌面效果仍由现有主题配置与减少动效偏好决定。

首页/探索内容表面需不透明，不能依赖调高全局遮罩抵御任意图片。实现可将主题 background 先合成至稳定底色，再把 surface 透明色合成到该背景，得到局部实色；文字颜色不满足对比度时使用可读黑/白兜底。所有转换只产生局部 `--mobile-*` 展示令牌，不改保存值。若实现不能可靠解析某个自定义 CSS 色值，使用已定义的稳定深色表面与浅字兜底，不让浏览器隐式回退为透明。

浅色预设也要验收；不强制把首页变成深色主题。文章继续采用已确认的独立深色阅读底板。背景图本身和作者的主题配色配置不被重置，不新增“阅读模式”切换开关。

### D12. 工程组织与验证先后

建议职责：MobileNavigation/MorePanel 只管理导航与模态；共享 ArticleList/SearchBar 负责请求与输入；列表 URL/恢复独立 helper 或 hook；MobileAuthorSummary 复用 settings 与 ContactLinks；样式限定到移动读者布局，避免触及 `.studio`。

先冻结布局、模态/URL 状态契约，再修搜索生命周期与列表状态，之后改首页/探索卡片，再完善文章/联系。并行只在共享接口确定且文件不重叠时进行；App.jsx/index.css 由单一集成人持有。不得让多个 agent 各改一套底栏、搜索状态或弹层逻辑。

## Risks / Trade-offs

- [首屏静态背景存在裁切差异] → 保留源图与自定义参数，不裁写文件；检查人像/横图/纯色/无图四类 fixture。
- [移动端隐藏装饰效果降低视觉动感] → 保留静态背景、选中态和轻量反馈，以阅读与触控为首要目标。
- [更多多一步操作] → 首页保留关于入口，联系图标收进更多，核心四项稳定；管理入口退居次级符合读者使用频率。
- [搜索 URL 与恢复逻辑触及桌面共用代码] → 分阶段实现、先测数据状态再测视觉，保留路由与 basename；有上限地缓存公共状态。
- [自定义主题色不可靠] → 局部实色与对比度兜底；不写回、不引入图片取色依赖。
- [移动键盘行为无法由桌面模拟证明] → 真机检查是发布前门槛；没有设备时明确未验证，不把截图当作真机通过。
- [CSS 断点/字体可能被读者设置覆盖] → 统一断点令牌，输入与关键命中尺寸局部约束；检查 760/761/1023/1024 边界。

## Migration Plan

2. 获准实施后逐阶段完成任务，优先以隔离数据库和上传目录运行；不重置真实设置。
3. 先完成移动布局和状态兼容，再进行桌面/子路径/认证回归及真机验收；无需数据库迁移。
